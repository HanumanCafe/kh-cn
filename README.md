# បកប្រែ ខ្មែរ ⇄ 中文

កម្មវិធីបកប្រែសំឡេងសម្រាប់ iPhone។ អ្នកនិយាយខ្មែរ → កម្មវិធីបកប្រែជាភាសាចិន ហើយអានឲ្យឮ។ ភ្ញៀវនិយាយចិន → កម្មវិធីបកប្រែជាខ្មែរ ហើយអានឲ្យឮ។

**បើកកម្មវិធី៖ <https://hanumancafe.github.io/kh-cn/>** (ដាក់លើ GitHub Pages ពី repository `HanumanCafe/kh-cn`)

## អ្វីដែលកម្មវិធីធ្វើបាន

- ប៊ូតុងធំពីរ៖ **ខ** សម្រាប់អ្នកនិយាយខ្មែរ និង **中** សម្រាប់អ្នកនិយាយចិន
- ឈប់ថតដោយខ្លួនឯង ពេលអ្នកឈប់និយាយ (ឬចុចប៊ូតុងម្តងទៀត)
- បង្ហាញពាក្យដែលបាននិយាយ ការបកប្រែ និង Pinyin
- អានការបកប្រែឲ្យឮ៖ ភាសាចិនប្រើសំឡេង iPhone, ភាសាខ្មែរប្រើសំឡេង Gemini (iPhone គ្មានសំឡេងខ្មែរ)
- **របៀបទល់មុខគ្នា** (ប៊ូតុង ⇅)៖ ដាក់ទូរសព្ទលើតុ ពាក់កណ្តាលអេក្រង់បង្វិលទៅភ្ញៀវចិន ម្នាក់មួយប៊ូតុង
- វាយអក្សរបកប្រែក៏បាន (ប៊ូតុងក្តារចុច)
- បើចុចប៊ូតុងខុសភាសា កម្មវិធីនៅតែស្គាល់ ហើយបកប្រែត្រូវ
- រក្សាប្រវត្តិសន្ទនាក្នុងទូរសព្ទ

## ជំហានទី ១ — យក Gemini API key (ឥតគិតថ្លៃ)

1. ចូល <https://aistudio.google.com/apikey> ដោយគណនី Google
2. ចុច **Create API key**
3. ចម្លង key (ចាប់ផ្តើមដោយ `AIza…`) ទុក

## ជំហានទី ២ — ដាក់កម្មវិធីលើអ៊ីនធឺណិត (ត្រូវតែ https)

✅ **រួចហើយ** — កម្មវិធីនៅ <https://hanumancafe.github.io/kh-cn/>។ ពេលកែកូដ សូម upload ឯកសារដែលបានកែទៅ repository `HanumanCafe/kh-cn` នៅលើ GitHub (Add file → Upload files) — GitHub Pages នឹងធ្វើបច្ចុប្បន្នភាពក្នុង ១–២ នាទី។

iPhone អនុញ្ញាតឲ្យប្រើមីក្រូហ្វូន តែលើគេហទំព័រ `https://` ប៉ុណ្ណោះ។ វិធីផ្សេង (ឥតគិតថ្លៃ)៖

**Netlify Drop**

1. ចូល <https://app.netlify.com/drop> ហើយចុះឈ្មោះ (ឥតគិតថ្លៃ)
2. អូស folder `KH-CN` ទាំងមូល ទម្លាក់ចូលក្នុងប្រអប់
3. អ្នកនឹងទទួលបានអាសយដ្ឋានដូចជា `https://xxxx.netlify.app`

វិធីផ្សេងទៀត៖ GitHub Pages, Cloudflare Pages ឬ hosting ផ្ទាល់ខ្លួន — ឲ្យតែមាន https។

> ឯកសារទាំងអស់គ្មាន API key ទេ (key ដាក់ក្នុងទូរសព្ទពេលប្រើ) ដូច្នេះដាក់លើអ៊ីនធឺណិតមិនអីទេ។

## ជំហានទី ៣ — ដំឡើងលើ iPhone

1. បើក <https://hanumancafe.github.io/kh-cn/> ក្នុង **Safari**
2. ចុចប៊ូតុង **Share** (ការ៉េមានព្រួញឡើងលើ)
3. ជ្រើស **Add to Home Screen** → **Add**
4. បើក App ពីអេក្រង់ដើម → ចុចប៊ូតុងការកំណត់ (ខាងស្តាំលើ) → បិទភ្ជាប់ API key → ចុច **សាកល្បង key**
5. ពេលទូរសព្ទសួរ ចុច **Allow** ឲ្យប្រើមីក្រូហ្វូន

## តម្លៃ និងដែនកំណត់

- Gemini មានកម្រិតឥតគិតថ្លៃ — គ្រប់គ្រាន់សម្រាប់ប្រើផ្ទាល់ខ្លួន ប៉ុន្តែមានកំណត់ចំនួនដងក្នុងមួយនាទី និងមួយថ្ងៃ (មើលចំនួនពិតនៅ AI Studio)។
- សំឡេងអានខ្មែរ (Gemini TTS) ជាផ្នែកដែលឆាប់អស់កំណត់ជាងគេ។ ពេលអស់ កម្មវិធីប្តូរទៅម៉ូដែលផ្សេងដោយខ្លួនឯង ហើយបើអស់ទាំងអស់ នៅតែបង្ហាញអក្សរ។
- សំឡេងចិនប្រើសំឡេង iPhone — ឥតកំណត់ ឥតគិតថ្លៃ។
- បើប្រើច្រើន អាចបើក billing ក្នុង AI Studio។ តម្លៃថោកណាស់ — ប្រហែល ១–៣ ដុល្លារ ក្នុងការបកប្រែ ១០០០ ដង (ប៉ាន់ស្មានតាមតម្លៃឆ្នាំ ២០២៦)។

## ឯកជនភាព

- API key និងប្រវត្តិសន្ទនា រក្សាទុកតែក្នុងទូរសព្ទរបស់អ្នក
- សំឡេង និងអក្សរ ត្រូវផ្ញើទៅ Google Gemini ដើម្បីបកប្រែ
- ក្នុងកម្រិតឥតគិតថ្លៃ Google អាចប្រើទិន្នន័យដើម្បីកែលម្អសេវារបស់ខ្លួន — កុំនិយាយព័ត៌មានសម្ងាត់ (លេខកាត ពាក្យសម្ងាត់ ។ល។)

## សាកលើកុំព្យូទ័រមុន (ស្រេចចិត្ត)

កុំព្យូទ័រអនុញ្ញាតមីក្រូហ្វូនលើ `http://localhost` ដោយមិនបាច់ https៖

- **VS Code**៖ ដំឡើង extension «Live Server» → ចុចស្តាំលើ `index.html` → **Open with Live Server**
- ឬ **Python**៖ បើក Command Prompt ក្នុង folder នេះ ហើយវាយ `python -m http.server 8000` រួចបើក <http://localhost:8000>

```
KH-CN/
├── index.html            ទំព័រកម្មវិធី
```
